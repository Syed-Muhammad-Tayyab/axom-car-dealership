# 🤝 Contributing to Axom

Thanks for considering a contribution! 🚗💨

1. **Fork** the repository and create a branch: `git checkout -b feature/amazing-feature`
2. Make your changes (keep HTML semantic, CSS variables for colors, vanilla JS only).
3. Test in **light & dark** mode and on **mobile & desktop**.
4. Commit using clear messages: `feat: add car search filter`
5. Push and open a **Pull Request**.

## Commit convention
| Type | Use for |
|------|---------|
| `feat` | a new feature |
| `fix` | a bug fix |
| `style` | CSS / UI-only changes |
| `docs` | documentation |
| `refactor` | code cleanup without behavior change |

Be kind and respectful. 💛
